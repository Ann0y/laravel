# 景区售票系统 数据库设计

> 文档版本：v1.0　　编制日期：2026-10-27
> 来源：自《景区售票系统需求规格说明书》v1.2 第 6 章拆分，独立维护
> 实现载体：`back-end/database/migrations/`（Laravel 迁移，建表即代码）；演示数据见 `database/seeders/DatabaseSeeder.php`
> 状态图例：本章表结构均与迁移文件一一对应，可通过 `php artisan migrate --seed` 完整复现

---

## 1. 设计约定

| 约定项 | 规则 |
| --- | --- |
| 数据库 / 字符集 | MySQL 8.0，库名 `scenic_ticket`，字符集 `utf8mb4`，引擎 InnoDB |
| 主键 | 所有表统一使用 `id BIGINT` 自增主键 |
| 命名 | 表名、字段名小写下划线；唯一约束前缀 `uk_`，普通索引前缀 `idx_`，外键前缀 `fk_`；预留字表名避免使用 `order`（采用 `sale_order`） |
| 时间 | 统一 `DATETIME`；仅日期用 `DATE`，仅时段用 `TIME`；`create_time` 默认 `CURRENT_TIMESTAMP` |
| 金额 | `DECIMAL(10,2)` |
| 逻辑删除 | **主数据表**（`sys_user` / `visitor` / `operator` / `scenic_area` / `ticket_type` / `ticket_stock`）统一含 `del_flag TINYINT DEFAULT 0`（0 正常 / 1 删除）；**业务流水表**（`sale_order` / `ticket` / `refund_record` / `ticket_review`）不物理、不逻辑删除，仅通过状态字段流转保留痕迹 |
| 敏感信息 | 游客身份证号（优惠购票实名需要）加密存储（AES），列表展示脱敏（保留前 6 后 4）；口令 BCrypt 单向加密 |
| 冗余计数 | `ticket_stock.sold_count` 为**冗余缓存字段**，由业务写入时同步更新，查询性能优先，允许与明细短暂不一致 |

## 2. 表清单与实体关系

| 表名 | 说明 | 类型 | 迁移文件 |
| --- | --- | --- | --- |
| `sys_user` | 登录用户（管理员 / 票务员 / 游客） | 主数据 | `0001_01_01_000000_create_users_table` |
| `visitor` | 游客档案 | 主数据 | `2026_01_01_000001_create_master_tables` |
| `operator` | 票务员档案 | 主数据 | 同上 |
| `scenic_area` | 景区信息 | 主数据 | 同上 |
| `open_day` | 园区开放日期 | 主数据 | 同上 |
| `ticket_type` | 票种（含价格） | 主数据 | 同上 |
| `ticket_stock` | 每日售票额度 | 主数据 | 同上 |
| `sale_order` | 售票订单 | 流水 | `2026_01_01_000002_create_business_tables` |
| `ticket` | 门票（含核销码） | 流水 | 同上 |
| `refund_record` | 退票申请与审核 | 流水 | 同上 |
| `ticket_review` | 游园评价（一票一评） | 流水 | `2026_01_01_000003_create_review_table` |

**实体关系**：

- `sys_user` 1 — 1 `visitor`（`visitor.user_id`）
- `sys_user` 1 — 1 `operator`（`operator.user_id`）
- `scenic_area` 1 — N `open_day`（`open_day.area_id`，本期单景区恒为 1 条关系，保留扩展）
- `ticket_type` 1 — N `ticket_stock`（`ticket_stock.type_id`）；`open_day` 1 — N `ticket_stock`（`ticket_stock.open_day_id`）
- `visitor` 1 — N `sale_order`；`ticket_type` 1 — N `sale_order`
- `sale_order` 1 — N `ticket`（按数量出票）；`ticket_type` 1 — N `ticket`
- `ticket` 1 — N `refund_record`（一票可多次申请，最新一条生效）；`ticket` 1 — 1 `ticket_review`（一票一评）
- `sys_user`（票务员）1 — N `sale_order`（`sale_order.operator_id`，窗口渠道经办人）

## 3. 表结构详细设计

### 3.1 `sys_user` 登录用户

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) | NOT NULL, UNIQUE `uk_username` | 登录名 |
| password | VARCHAR(100) | NOT NULL | BCrypt 密文 |
| name | VARCHAR(50) | NOT NULL | 显示姓名（各档案表不再重复存姓名） |
| role | VARCHAR(20) | NOT NULL, DEFAULT 'visitor' | `admin` / `operator` / `visitor` |
| status | TINYINT | NOT NULL, DEFAULT 1 | 1 启用 / 0 停用 |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| del_flag | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除 |

### 3.2 `visitor` 游客档案

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, UNIQUE `uk_user`, FK `fk_visitor_user` → `sys_user.id` | 关联登录账号 |
| id_card | VARCHAR(64) | NULL, UNIQUE `uk_id_card` | 身份证号（AES 密文，展示脱敏；优惠实名需要） |
| phone | VARCHAR(20) | NULL | 联系电话 |
| status | VARCHAR(20) | NOT NULL, DEFAULT '正常' | 正常 / 停用 |
| del_flag | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除 |

索引：`idx_status(status)`。

### 3.3 `operator` 票务员档案

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, UNIQUE `uk_user`, FK `fk_operator_user` → `sys_user.id` | 关联登录账号 |
| code | VARCHAR(20) | NOT NULL, UNIQUE `uk_code` | 票务工号 |
| window_no | VARCHAR(20) | NULL | 常用窗口编号 |
| phone | VARCHAR(20) | NULL | 联系电话 |
| status | VARCHAR(10) | NOT NULL, DEFAULT '在职' | 在职 / 停用 |
| del_flag | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除 |

### 3.4 `scenic_area` 景区信息

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| name | VARCHAR(50) | NOT NULL | 景区名称 |
| description | VARCHAR(500) | NULL | 景区简介（富文本可后扩） |
| address | VARCHAR(100) | NULL | 地址 |
| open_time | VARCHAR(50) | NULL | 开放时间（如"08:30–17:00"） |
| notice | VARCHAR(255) | NULL | 游园公告 |
| default_capacity | INT | NOT NULL, DEFAULT 5000 | 全局默认每日入园额度兜底 |
| del_flag | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除 |

### 3.5 `open_day` 园区开放日期

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| area_id | BIGINT | NOT NULL, FK `fk_day_area` → `scenic_area.id` | 景区 |
| open_date | DATE | NOT NULL | 游园日期 |
| capacity | INT | NOT NULL, DEFAULT 5000 | 当日入园总容量 |
| status | VARCHAR(10) | NOT NULL, DEFAULT '开放' | 开放 / 闭园 |
| del_flag | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除 |

约束：UNIQUE `uk_area_date`(`area_id`, `open_date`)。
索引：`idx_date(open_date)`。

### 3.6 `ticket_type` 票种

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| type_code | VARCHAR(20) | NOT NULL, UNIQUE `uk_code` | 票种编码（ADULT / CHILD / STUDENT / SENIOR / FAMILY / GROUP / MILITARY …） |
| type_name | VARCHAR(50) | NOT NULL | 票种名称（成人票 / 儿童票 …） |
| price | DECIMAL(10,2) | NOT NULL | 现售价 |
| applicable | VARCHAR(100) | NULL | 适用人群说明 |
| refundable | TINYINT | NOT NULL, DEFAULT 1 | 1 可退 / 0 不可退 |
| status | VARCHAR(10) | NOT NULL, DEFAULT '在售' | 在售 / 停售 |
| del_flag | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除 |

### 3.7 `ticket_stock` 每日售票额度

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| open_day_id | BIGINT | NOT NULL, FK `fk_stock_day` → `open_day.id` | 对应开放日 |
| type_id | BIGINT | NOT NULL, FK `fk_stock_type` → `ticket_type.id` | 票种 |
| quota | INT | NOT NULL | 当日该票种可售额度 |
| sold_count | INT | NOT NULL, DEFAULT 0 | 已出票张数（**冗余缓存**） |
| status | VARCHAR(10) | NOT NULL, DEFAULT '正常' | 正常 / 已售罄 / 停售 |
| del_flag | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除 |

约束：UNIQUE `uk_day_type`(`open_day_id`, `type_id`)。
索引：`idx_type_date(type_id)`。
说明：剩余额度 = `quota − sold_count`，不冗余存"剩余"字段。

### 3.8 `sale_order` 售票订单

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| order_no | VARCHAR(32) | NOT NULL, UNIQUE `uk_order_no` | 订单号（`SO` + 日期 + 流水） |
| visitor_id | BIGINT | NOT NULL, FK `fk_order_visitor` → `visitor.id` | 购票游客 |
| type_id | BIGINT | NOT NULL, FK `fk_order_type` → `ticket_type.id` | 票种 |
| visit_date | DATE | NOT NULL | 游园日期（门票支持改期，审核回补按门票各自的 visit_date 计） |
| quantity | INT | NOT NULL | 购买张数 |
| unit_price | DECIMAL(10,2) | NOT NULL | 下单时单价快照 |
| total_amount | DECIMAL(10,2) | NOT NULL | 实付金额（= unit_price × quantity） |
| channel | VARCHAR(10) | NOT NULL, DEFAULT '线上' | 线上 / 窗口 |
| pay_method | VARCHAR(20) | NULL | 模拟支付 / 现金 / 扫码 |
| pay_time | DATETIME | NULL | 支付完成时间 |
| operator_id | BIGINT | NULL, FK `fk_order_operator` → `operator.id` | 窗口经办票务员（线上渠道为空） |
| status | VARCHAR(10) | NOT NULL, DEFAULT '待支付' | 待支付 / 已支付 / 已使用 / 退款中 / 已退款 / 已取消 |
| cancel_time | DATETIME | NULL | 取消时间 |
| refund_time | DATETIME | NULL | 整单退款完成时间 |

约束：UNIQUE `uk_order_no`(`order_no`) 以订单号承载唯一性；订单明细以 `ticket` 表为据（一单出多票，核销码归属订单）。
索引：`idx_visitor_status(visitor_id, status)`、`idx_visit_date(visit_date)`。

### 3.9 `ticket` 门票

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| ticket_no | VARCHAR(32) | NOT NULL, UNIQUE `uk_ticket_no` | 核销码（`TK` + 随机 16 位；二维码即编码内容） |
| order_id | BIGINT | NOT NULL, FK `fk_ticket_order` → `sale_order.id` | 所属订单 |
| type_id | BIGINT | NOT NULL, FK `fk_ticket_type` → `ticket_type.id` | 票种（冗余自订单，便于查询） |
| visit_date | DATE | NOT NULL | 游园日期（核销有效期判断；**门票独立可改期**，改期后与订单 visit_date 一致） |
| unit_price | DECIMAL(10,2) | NOT NULL | 张票价（订单单价快照，退票退款金额依据） |
| status | VARCHAR(10) | NOT NULL, DEFAULT '未检票' | 未检票 / 已检票 / 已退款 / 已过期 |
| check_time | DATETIME | NULL | 核销时间 |
| checker_id | BIGINT | NULL, FK `fk_ticket_checker` → `sys_user.id` | 核销人（票务员） |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 出票时间 |

索引：`idx_order(order_id)`、`idx_visit_date_status(visit_date, status)`。
说明：不单存"退款金额"，默认等于 `unit_price`；退票审核的额度回补以**门票自身 visit_date** 定位额度行（支持改期场景）。

### 3.10 `refund_record` 退票申请与审核

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| ticket_id | BIGINT | NOT NULL, FK `fk_refund_ticket` → `ticket.id` | 申请退的门票 |
| visitor_id | BIGINT | NOT NULL, FK `fk_refund_visitor` → `visitor.id` | 申请游客（窗口代退为经办票务员） |
| reason | VARCHAR(255) | NOT NULL | 退票原因 |
| refund_amount | DECIMAL(10,2) | NOT NULL | 申请退款金额（默认为张票价） |
| apply_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 申请时间 |
| audit_status | VARCHAR(10) | NOT NULL, DEFAULT '待审核' | 待审核 / 已通过 / 已驳回 / 已撤回（游客撤回） |
| auditor_id | BIGINT | NULL, FK `fk_refund_auditor` → `sys_user.id` | 审核人 |
| audit_opinion | VARCHAR(255) | NULL | 审核意见 |
| audit_time | DATETIME | NULL | 审核时间 |

索引：`idx_ticket(ticket_id)`、`idx_status(audit_status)`。

### 3.11 `ticket_review` 游园评价

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| ticket_id | BIGINT | NOT NULL, FK `fk_review_ticket` → `ticket.id`，UNIQUE `uk_review_ticket` | 被评价门票（一票一评） |
| visitor_id | BIGINT | NOT NULL, FK `fk_review_visitor` → `visitor.id` | 评价游客 |
| rating | TINYINT | NOT NULL | 星级 1-5 |
| content | VARCHAR(255) | NULL | 评价内容（可仅星级） |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 评价时间 |

索引：UNIQUE `uk_review_ticket(ticket_id)`、`idx_review_time(create_time)`。
说明：仅"已检票"门票可评；公开接口展示最新评价并按姓名首字脱敏（`张三 → 张*`）；业务流水表不做物理 / 逻辑删除。

## 6. 迁移与数据复现

| 操作 | 命令 | 说明 |
| --- | --- | --- |
| 建表 | `php artisan migrate` | 按 4 个迁移文件创建全部 11 张表 |
| 建表 + 演示数据 | `php artisan migrate --seed` | 首次部署推荐 |
| 全量重置 | `php artisan migrate:fresh --seed` | 清空重建（开发 / 演示用） |
| 生成 SQL | `mysqldump scenic_ticket > scenic_ticket.sql` | 需提交"数据库文件"时的导出方式 |

种子数据内容（`DatabaseSeeder`）：景区 1 家、票种 7 种、未来 7 天开放日满配额度（含部分预置已售量）、昨日开放日、3 个演示账号（admin / window01 / demo）、2 笔演示订单（已支付 / 已使用各 1，含已核销门票）、2 条游园评价。
