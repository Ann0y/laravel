《PHP 框架应用》课程设计任务书


一、课程设计总体任务

本课程设计不设定统一题目，由学生根据个人兴趣、专业方向或实际需求自主选题。学生须使用 PHP 框架（Laravel）独立设计并实现一个结构清晰、功能完整、可运行、可演示的 Web 应用。项目应具有明确的业务场景、合理的数据结构，并体现控制器与路由、Blade 展示层或者分离前端展示层、数据传递、后端数据操作和数据验证等课程核心知识点。


二、选题要求

1. 自主选题、一人一题。选题必须具有明确的应用场景和核心业务对象，不得只制作静态页面或与课程知识点无关的简单练习。

2. 项目数据应不少于 3 条记录，每条记录不少于 3 个有意义的业务字段；数据之间应具有基本业务逻辑。

3. 技术路线须使用 PHP 框架（Laravel）、MVC 分层、Eloquent 模型或查询构造器，并使用课程允许的数据库完成数据存取。

4. 不得抄袭他人项目或直接提交网络模板。允许参考公开资料，但核心业务、数据设计、关键代码和报告须由本人完成并能解释实现过程。


三、功能与考核要求

课程设计采用过程性与成果性评价相结合的方式，总分 100 分。具体考核维度如下：

1. 控制器和路由（20 分）
   正确创建控制器类并规范命名、命名空间和存放位置；控制器方法结构完整（定义/获取数据→返回结果）；正确编写路由文件。

2. 展示层与循环（15 分）
   正确创建 Blade 视图或前端页面文件；目录与命名合理并体现项目主题；循环体内正确输出各字段，无遗漏、无重复，与 HTML 标签配合正确。

3. 传递数据（10 分）
   使用正确的数据传递方式；传递给展示层的数据不少于 3 条，每条字段不少于 3 个，字段命名清晰有意义。

4. 后端数据操作（15 分）
   模型属性配置正确，具备批量赋值保护；使用 Eloquent 模型或查询构造器获取数据；合理使用 where、orderBy、关联查询或 Factory/Seeder。

5. 数据验证（10 分）
   对请求数据使用 $request->validate()，验证规则合理；验证失败时能够通过页面或接口返回清晰错误反馈。

6. 质量工程（30 分）
   代码规范与注释合理；数据与业务逻辑自洽；设计报告完整；独立完成并用心打磨；项目结构清晰、可复现；能够准确回答“为什么这样写”。

合计：100 分


四、需要提交的内容

1. 项目源代码及数据库文件：包括完整项目目录、核心代码、迁移/Seeder（或数据库 SQL）、必要依赖说明；项目应能在干净环境中按说明复现运行。

2. 项目说明书/README：包括运行环境、安装步骤、数据库初始化、默认账号（如有）、主要功能入口和测试数据说明。

3. 功能演示视频：完整演示主要功能、数据循环、数据传递、后端查询与数据验证效果。视频统一命名为“班级-序号-姓名-功能演示.mp4”。

4. 课程设计报告：使用《PHP 框架应用》课程设计报告模板，内容须与源代码、数据库和视频一致，包含关键代码、运行截图、问题解决过程、自评与总结。


五、提交规范要求

• 提交目录建议命名为“班级-学号-姓名-项目名称”，目录内按“源码”“数据库”“报告”“演示视频”分类整理。

• 演示视频、报告、源码和数据库文件须命名清楚，不得使用“新建文件夹”“最终版”等无意义名称。

• 项目运行时页面跳转应正常，主要功能可操作，无影响演示的明显错误；数据库须提供可复现的数据来源。

• 报告排版应清晰，代码、截图和文字说明对应；凡引用他人资料，应按规范注明来源。
